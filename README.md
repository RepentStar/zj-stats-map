# 浙江省统计专题地图 WebGIS

基于 Vite + 原生 JavaScript + OpenLayers + ECharts 的静态 WebGIS，无后端
UI 使用 Tailwind CSS v4 + [basecoat-css](https://basecoatui.com)（shadcn/ui 的原生 HTML/CSS 实现，无需 React），底图为降饱和处理的天地图矢量底图（`src/map/tianditu.js`），省外加半透明遮罩突出浙江轮廓；地图上的比例符号与产业饼图由 ECharts 经 `ol-echarts` 叠加到 OpenLayers 上（`src/map/overlay.js`）
行政区划仅含浙江省及 11 个地级市，当前数据为 2016–2025 年人口、GDP、产业结构与城镇居民收入，共 11 项指标

## 开发环境

- Node.js 20.19+（20 系列）或 22.12+，建议使用 Node.js 24 LTS
- npm
- Python 3.10+，校验脚本仅使用标准库，无需安装 Python 依赖

```bash
npm ci
npm run data:check
npm run dev
```

访问终端输出的本地地址，默认展示最近年份的浙江省 11 市专题地图。

控制面板、时间轴和图表均为可拖动、缩放和关闭的悬浮窗口；图例卡片固定在左下角，显示大号当前年份，播放时同步跳动。工具栏可重新打开控件、关闭全部窗口或返回全省视图。

地图按指标性质选择表达方式：

- **总量指标**（常住人口、GDP、三次产业增加值）：比例符号，气泡面积表示数值，比例尺跨年份固定，播放时可直接比较增长。
- **比率与人均指标**（人口密度、人均 GDP、城镇居民收入）：分级设色，城市名下直接标注数值。
- **产业占比**：各市三次产业饼图，深色扇区为当前选择的产业占比，另两项为浅灰，饼图大小表示三产增加值合计。

地图只使用一套蓝色色阶，选中城市用橙色强调。图例逐档列出数值范围与当年城市数。鼠标悬停城市显示当年数值、全省排名和较上年变化；城市排行条形颜色与地图分级一致。

支持切换常住人口、人口密度、GDP、人均 GDP、三次产业增加值及占比、城镇居民人均可支配收入，多选城市、年份滑块及自动播放。地图与图例使用跨年份固定分级，城市按钮可查看当前数值。

界面保留操作标签、年份、单位、图例和必要状态反馈，省去说明段落与数据口径提示。项目侧重可视化课设展示。

点击“新建图表”选择：

- **人口占比**：各市常住人口构成。
- **城市排行**：当前年份和指标的城市对比。
- **历年趋势**：多城市年度变化，虚线标记当前年份。
- **产业占比**：三次产业占比雷达小多图，每市一个小雷达，三轴范围按全部年份实际占比取整到 5% 并跨年份固定（底部注明范围）。
- **产业增加值**：三次产业增加值横向堆叠图，按城市对比规模，单位为亿元。

图表以独立窗口保留生成时的指标，可并排对比；所有已打开图表的城市范围随地图或控制面板的地区选择实时更新，清空选择时展示全省 11 市，范围说明同步更新。所有图表的年份跟随时间轴实时更新，支持滑块、上一年/下一年和自动播放；历年趋势保留完整序列并移动当前年份虚线。点击图形可联动城市选择或地图年份。

两类产业图表始终读取同一市年的三项产业指标，不受地图当前指标影响；占比直接读取预计算值，不重新计算或归一化。缺少任一产业项的城市不展示，并提示缺失城市数量；全部缺失时显示空状态，不补零。

## 常用命令

| 命令                 | 用途                                                     |
| -------------------- | -------------------------------------------------------- |
| `npm run dev`        | 启动 Vite 开发服务器                                     |

| `npm run preview`    | 本地预览构建产物                                         |

## 目录与接口

```text
public/data/
  geo/zhejiang_city.json  # 规范化市级边界，adcode 为字符串
  regions.csv            # 1 省 + 11 市，含面积与中心点
  indicators.csv         # 任务 1–4 共 11 项指标
  stats.csv              # 长表；当前 1210 条记录
  raw/stats_task1.csv     # 人口与密度原始提交
  raw/stats_task2.csv     # GDP 与人均 GDP 提交原值
  raw/stats_task3.csv     # 三次产业增加值与预计算占比原始提交
  raw/stats_task4.csv     # 收入原始提交，合并时将城市名称转换为编码
scripts/merge_stats.py    # CSV 合并、校验与覆盖率报告
src/
  data/loader.js         # 并行加载、CSV 解析与编码关联
  data/store.js          # 内存索引与共享选择状态
  data/indicators.js     # 指标常量与数值格式化
  map/                   # 市级图层、跨年份固定断点与选择样式
  charts/                # 图表条件快照、环形/排行/趋势/产业雷达与堆叠图
  ui/                    # 悬浮窗口管理、指标选择、停靠图例、悬停提示、时间轴与播放状态机
  main.js                # 全屏地图工作台与按需创建图表入口
tests/                   # Node.js 与 Python 标准库测试
```

图表窗口运行模块与所选类型并行动态加载，排行与产业堆叠图共用柱状图模块。地图叠加层在首页注册 ECharts 饼图和散点图以绘制产业饼图与总量气泡，窗口复用已加载的依赖。后续窗口复用模块缓存。构建生成 `dist/.vite/manifest.json`，供加载检查使用。具体体积及复现方法见 [加载性能记录](docs/loading_performance.md)。

`loadData()` 使用 Vite 的 `BASE_URL` 加载资源，返回解析后的数据。编码始终保留为字符串，数值和年份显式转换；人口密度与产业占比直接读取，不在前端计算

```js
const store = createStore(await loadData());
store.getValue('pop_resident', 2016, '330100'); // 918.8；缺失时返回 null
store.getSeries('pop_resident', '330100'); // [[2016, 918.8], ...]
const unsubscribe = store.subscribe((state) => {
    /* 更新地图、图表、控件 */
});
store.setState({ year: 2020, selectedCities: ['330100'] });
unsubscribe();
```

索引结构为 `Map<indicator, Map<year, Map<adcode, number>>>`。共享状态包含 `indicator`、`year` 和 `selectedCities`；默认选择首个指标和最新年份，不预选城市。支持多城市选择，拒绝省级与未登记地区

## 数据校验

脚本检查列名与顺序、六位字符串编码、地区及边界关联、重复主键、有限非负数值、指标登记、人口密度公式和产业占比公式。密度允许误差 ≤ 0.1 人/km²；产业占比以三次产业增加值之和为分母，单项误差与合计偏离 100% 均须 ≤ 0.01 个百分点。校验失败不会覆盖输出文件。覆盖率按登记城市、当前数据年份和启用指标计算，缺失行只报告、不补零

- 任务 2 仅校验格式、主键与编码关联；按用户要求跳过人均 GDP 公式及 GDP 与产业合计的一致性检查，提交数值保持不变。
- 当前覆盖率：11 市 × 10 年 × 11 指标 = 1210 行，缺失 0 行
- 原始收入 CSV 的 `城市,year,indicator,value` 在合并入口按地区表的全名或简称精确匹配；未知名称报错。输出与前端仍严格使用 `adcode,year,indicator,value`
- 来源、文件对应关系与本次校验结果见 [数据接入记录](docs/data_sources.md)。收入提交未附来源说明，产业数值为当年初步核算口径
- 省级不提供统计值，面积是地区表的静态属性
- 市级边界由仓库中的 `public/data/geo/浙江省.geojson` 规范化而来，保留原始几何。

## 开发阶段

依据 [设计文档 v0.2](docs/webgis_design_v0.2.md)，已完成 **M0–M5**：数据加载与校验、市级专题地图、时间轴、GDP/人均 GDP、产业图表与收入指标

2026-10-27，用户确认已完成浏览器交互验收。本次后续维护统一了文档中的图表城市范围联动约定，并完成按类型加载优化；修改后的验证采用自动化测试、数据校验及生产构建依赖检查。

- M1 已实现：仅初始化时解析并投影 GeoJSON（EPSG:4326 → EPSG:3857），状态更新调用 `layer.changed()`，不重复加载边界；图例与地图共用断点。底图使用天地图 WMTS（需联网）
- M2 已实现：年份滑块、逐年播放/暂停、速度/循环设置；所有按需创建的图表保留各自生成时的指标，地区范围与年份随共享选择实时更新。地图与控件使用共享状态，图表点击可更新地图；不默认渲染数据表
- 已接入任务 3、4 数据：新增 7 项指标可使用现有分级设色、固定图例、时间轴、城市排行和历年趋势。M5 收入指标已完成
- M4 已完成：产业占比雷达图、三次产业增加值堆叠图，复用现有图表快照、独立窗口和城市点击联动，覆盖 2016–2025 年全部 11 市
- M3 已完成：GDP（亿元）使用比例气泡，人均 GDP（元/人）使用分级设色，两者支持指标切换、跨年份固定比例尺或分级、图例、时间轴、城市排行和历年趋势。图表保留生成时的指标，城市范围跟随地区选择，年份跟随时间轴；长数值标签适配窄窗口。按用户要求保留提交数值，不重算人均 GDP。县区下钻不在范围内
