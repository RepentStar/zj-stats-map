## 校验结果

| 检查 | 结果 |
|---|---|
| 地区、年份 | 两份新数据均覆盖浙江 11 市、2016 至 2025 年 |
| 指标与条数 | 新增 7 项，每项 110 条，共 770 条 |
| 主键与数值 | 无重复主键、空值、非数值或非有限值；数值均非负 |
| 编码关联 | 全部映射到地区表及 GeoJSON 中的市级编码；无省级统计行 |
| 产业占比公式 | 330 项全部通过；相对 `gdp_x / (一产 + 二产 + 三产) × 100` 的最大误差约 0.004999 个百分点，小于 0.01 |
| 产业占比合计 | 110 组市年组合全部通过；合计范围 99.99% 至 100.01% |
| 原有人口密度 | 110 项全部通过，公式误差不超过 0.1 人/km² |
| 合并覆盖率 | 11 市 × 10 年 × 9 指标 = 990/990 条，缺失 0 条 |

占比分母使用同一市年的三次产业增加值之和，不依赖尚未提交的任务 2 `gdp`，不新增 GDP 或人均 GDP 指标。前端只读取预计算占比。

## 复现

```bash
npm run data:merge
npm run data:check
npm test
npm run build
```

合并脚本读取项目内全部 `raw/*.csv`，规范收入编码后统一校验，按编码、年份、指标排序并原子替换 `stats.csv`；失败时保留上一次输出。原始副本与外部提交文件保持一致，重复运行不会重复追加记录。

新增指标沿用现有地图、图例、年份/播放、排行和趋势图。人口占比图继续只读取常住人口。M4 雷达图和堆叠图留作独立后续开发。
