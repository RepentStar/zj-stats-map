# 图表模块

| 文件                    | 职责                                   |
| ----------------------- | -------------------------------------- |
| `snapshot.js`           | 静态条件快照与跟随共享状态的图表数据源 |
| `exploreOptions.js`     | 人口占比、城市排行配置及图表类型分派   |
| `lineOptions.js`        | 趋势序列、单位、工具提示与当前年份标记 |
| `industryOptions.js`    | 产业占比雷达图和增加值堆叠图配置       |
| `colors.js`             | 稳定的城市配色与三次产业配色           |
| `explore.js`            | SVG 渲染、交互、尺寸观察与销毁         |
| `loadType.js`、`types/` | 按类型加载和注册 ECharts 模块          |
| `line.js`               | 直接订阅 Store 的独立趋势组件          |

## 数据源与联动

工作台使用 `createTimelineChartSource(store, type)` 固定创建时的指标，年份与城市范围跟随共享选择；无选择时展示全部地级市。`createChartSnapshot(store, type)` 提供完全静态的条件快照，供配置构建使用

`createExploreOption(source, type)` 支持 `pie/rank/line/radar/stack`，不修改共享状态。人口占比固定使用常住人口；排行和趋势使用创建时的指标；产业图表固定读取三次产业数据

`createExploreChart({ target, snapshot, type, onSelectCity, onSelectYear })` 中 `snapshot` 传入动态数据源，返回销毁函数。折线点击选择年份，其余图表点击选择城市。更新时替换配置以清除过期城市与空状态，并保留图例状态；销毁时取消订阅、尺寸观察并释放图表实例

## 数值表达

人口占比以所选城市的有效人口合计为分母，合计为零时显示空状态。排行按数值降序排列，颜色与地图一致。趋势保留完整年份序列，缺失值为 `null`，当前年份仅绘制一条虚线

产业雷达图读取预计算占比，每市一个雷达，各轴范围按全部城市和年份的数据取整到 5%，跨年份固定。堆叠图读取三次产业增加值，单位为亿元。两类产业图表保留真实零值，跳过缺少任一所需产业项的城市并提示数量，全部缺失时显示空状态

## 按需加载

入口并行请求共享运行模块与所选类型模块，后续窗口复用模块缓存：

| 图表                 | 类型模块         |
| -------------------- | ---------------- |
| 人口占比             | `types/pie.js`   |
| 城市排行、产业增加值 | `types/bar.js`   |
| 历年趋势             | `types/line.js`  |
| 产业占比             | `types/radar.js` |

首页地图叠加层通过 `ol-echarts` 加载 ECharts 依赖。`npm run build:check` 检查窗口运行模块和类型入口的加载边界，输出首页及首次图表所需的静态依赖体积；产物字节数不代表网络耗时

`tests/chart-loading.test.js` 在独立进程中验证每种图表的首次注册和并发请求。图表类型变更时，同步更新加载映射、构建检查与独立加载测试
