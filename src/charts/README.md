# 图表模块（M2、M3、M4）

- `line.js`：选中城市的历年序列，支持多城市对比；标记当前年。
- `lineOptions.js`：纯配置构建函数，生成序列、单位、工具提示、城市固定颜色与标注，供运行时及测试共用。
- `snapshot.js`：提供静态快照和跟随时间轴的数据源，固定创建时的指标，城市范围与年份跟随共享选择。
- `exploreOptions.js`：环形人口占比图、横向城市排行图的纯配置，并复用折线图配置。
- `industryOptions.js`：产业占比雷达图、产业增加值堆叠图的纯配置，只展示完整三项数据的城市。
- `colors.js`：跨图表稳定的城市配色。
- `explore.js`：注册共享组件，负责 SVG 渲染、点击事件与销毁。
- `loadType.js`、`types/`：按所选类型动态加载并注册图表，排行与产业堆叠共用柱状图模块。入口并行请求共享运行模块与所选类型；其他类型延后到首次使用时加载，后续窗口复用模块缓存。

使用 `echarts/core` 按需引入图表及组件。通过 `store.getSeries(indicator, adcode)` 获取序列；缺失值保持 `null`，不插值。工作台图表固定创建时的指标，订阅共享年份及城市选择；地图与控件使用 `store.subscribe()` 同步共享状态。

工作台入口在用户请求时动态导入 `explore.js`，每次请求新建窗口。`createChartSnapshot(store, type)` 仍提供完全静态的条件快照；工作台使用 `createTimelineChartSource(store, type)` 固定指标，`getState()` 读取共享最新年份及城市范围，`subscribe()` 在年份或城市选择改变时通知并返回取消订阅函数。无选择时使用全部地级市，排除省级；饼图始终使用 `pop_resident`，不对密度做占比；产业图表固定读取三次产业指标，与地图当前指标无关。`createExploreOption(snapshot, type)` 接受上述数据源和 `pie/rank/line/radar/stack`，不修改共享 Store。

`createExploreChart({ target, snapshot, type, onSelectCity, onSelectYear })` 中 `snapshot` 传入时间轴数据源，返回销毁函数。饼图、排行、雷达图和堆叠图点击调用 `onSelectCity(adcode)`，折线点选调用 `onSelectYear(year)`；入口更新地图选择，手动选年时暂停播放。多个图表保留各自指标，共享同一时间轴年份及城市选择；清空选择时恢复全部 11 市。

地图、控制面板和图表点击均可更新城市范围，所有窗口即时同步。滑块、逐年按钮、播放和折线点击都会触发年份更新：人口占比、排行、产业雷达与堆叠图更新当年数值，趋势图保留完整历年序列，仅移动当前年份虚线。窗口条件文案和无障碍标签同步更新；异步加载期间改变年份，首次渲染读取最新年份。更新时替换旧配置以清除过期城市及空状态，并保留图例显隐与翻页状态。

饼图占比以本次城市范围内有效人口合计为分母。饼图与排行排除缺失观测，排行保留零值；无有效值时显示空状态，饼图人口合计为零时也不伪造占比。城市配色跨图表保持固定。生成失败可在当前窗口重试，模块加载失败提供重新加载页面入口，不影响地图；异步加载完成前检查窗口是否关闭，避免向已移除的节点初始化实例。

原 `createLineChart({ target, store, onSelectYear })` 仍可用于订阅完整 Store 的趋势组件；当前工作台通过 `explore.js` 和时间轴数据源渲染，避免新请求覆盖旧窗口。

当前年份使用虚线，工具提示显示年份、城市数值和单位。ResizeObserver 同步容器尺寸，销毁时取消年份订阅和观察器并释放图表实例；窗口关闭时另行取消条件文案订阅，关闭后不再响应时间轴变化。

排行和趋势图已支持任务 2 的 GDP/人均 GDP、任务 3 的三次产业增加值/预计算占比及任务 4 收入，单位和精度读取指标字典。人口占比图仍只读取常住人口。

M4 雷达图使用 `share_primary/secondary/tertiary`，各轴范围按全部年份实际占比取整到 5% 并跨年份固定，保留预计算精度，不归一化；每市一个小雷达（小多图），底部注明坐标范围。堆叠图使用 `gdp_primary/secondary/tertiary`，城市顺序沿用选择顺序，三产业顺序与配色固定，单位为亿元。两者工具提示列出当前市年的三项数值；缺少任一所需产业项的城市不展示，并提示缺失数量；全部缺失显示空状态，保留真实零值。任务 2 GDP/人均 GDP 直接读取独立提交值，不从产业合计推导。趋势图通过 ECharts 6 的 outerBounds 约束轴标签边界，排行按格式化数值长度预留右侧空间。

## 加载检查

`npm run build:check` 构建并读取 `dist/.vite/manifest.json`，验证首页不静态依赖图表运行模块及类型模块，共享模块不提前加载类型，单个类型不引入其他类型；输出首页及首次打开各类图表的静态依赖总体积（含共享依赖、去重统计）。这些是产物字节数，不代表实际网络耗时。

`tests/chart-loading.test.js` 为五类图表分别启动独立进程，验证首次注册所需组件即可完成 SVG 渲染，并覆盖并发窗口请求。新增图表类型时须同时更新类型映射、构建检查列表与独立加载测试。

地图叠加层通过 `ol-echarts` 在首页加载 ECharts 依赖，用于气泡和产业饼图；上述检查针对窗口模块入口，不表示 ECharts 内部实现全部延迟加载。合并后的实际体积见 [加载性能记录](../../docs/loading_performance.md)。
